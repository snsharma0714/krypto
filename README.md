# 💸 Krypt - Web3.0 Ethereum Transaction App

Krypt is a Web3.0 blockchain-based decentralized application (dApp) that allows users to send Ethereum transactions seamlessly through a beautiful and responsive frontend. It utilizes MetaMask for wallet connection and Solidity smart contracts deployed on the Sepolia Ethereum Testnet.

## 🚀 Features

- 🦊 MetaMask integration
- 🔒 Secure Ethereum transaction handling via smart contracts
- 🌐 Sepolia Ethereum testnet support
- 🎨 Modern React UI with animations
- 📜 Transaction history displayed on the frontend
- ✅ Admin wallet connection as an access gate

---

## 🛠️ Tech Stack

- **Frontend**: React.js, Tailwind CSS
- **Blockchain**: Solidity, Ethereum (Sepolia Testnet)
- **Wallet Integration**: MetaMask
- **Development Tools**: Hardhat, Ethers.js
